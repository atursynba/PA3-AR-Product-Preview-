# WebGL 3D Cube with Perspective Projection

## Description
This project demonstrates 3D rendering using pure WebGL and the `glMatrix` library. It presents a rotating 3D cube with perspective transformation, depth testing, and vertex coloring.

## Tech Stack
* HTML5 / CSS3
* JavaScript (ES6+)
* WebGL API
* glMatrix v2.8.1 (Math library for matrix operations)

## How to Run
1. Clone or download the repository.
2. Open `index.html` using **Live Server** in VS Code or any local web server.
3. Open browser developer tools (F12) to inspect WebGL logs if needed.
